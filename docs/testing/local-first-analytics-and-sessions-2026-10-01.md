# 本地优先统计与会话 UI — 2026-10-01

## 行为边界

| 接入状态 | 通用功能、本地仪表盘/记录 | HRouter 服务入口 | 云端账户数据 |
| --- | --- | --- | --- |
| 未配置 HRouter Key（包括仅有保留登录态） | 可用 | 隐藏 | 不挂载、不查询 |
| 任意 Agent 配置了 HRouter 端点与非空 Key，未登录 | 可用 | 显示快捷接入、登录、站点、公告 | 不挂载、不查询 |
| 已配置 Key 并登录 | 可用 | 显示 | 可切换至 HRouter 云端；显示账户账单、订单、密钥入口 |

- 产品品牌和“添加供应商”内主动选择的 HRouter 接入方式保留；不默认推送账户服务。
- 能力检测检查实际端点的 HTTPS 主机与凭据，不依据供应商名字、网站或 preset 标签；不把包含 `hrouter.net` 的其他域名当成 HRouter。
- 检测覆盖现有 11 个 Agent 配置适配器，使用供应商级查询键，响应新增、修改、删除与导入失效通知。
- Key 配置检测不等同于远端有效性验证，不向云端发送 Key 来判断导航权限。
- 撤销 Key 或登录后，云端页面立即卸载；托盘账户摘要清空。功能导览也过滤不可用的账户页面。

## 会话页

- 全宽容器，桌面为固定宽度列表与可伸缩详情；小于 `md` 时上下分栏。
- 列表、消息、目录、分组、展开及复制控件统一使用共享 React Button / Radix Select、Checkbox、Collapsible、Dialog、Tooltip、ScrollArea。
- 筛选器显示当前模式、Agent 文字；保留搜索、分组、批量删除确认、消息虚拟列表与继续会话逻辑。
- 补充空状态引导、清除筛选、Hermes 筛选选项、列表与消息读取失败状态。

## 本地数据

- 主导航“仪表盘”默认展示本地用量摘要、趋势；“使用记录”默认展示本地明细、供应商与模型维度。
- 通过已有 `sync_session_usage` 命令增量导入，完成后失效本地 usage 查询；可手动刷新、失败可重试。
- 原有后端目前支持 Claude Code、Codex、Gemini CLI、OpenCode、Grok Build 会话用量，以及本地代理请求。没有声称所有 Agent 都支持会话用量。
- 不重建或删除原始会话，不因进入统计页改变 Agent 接入配置；本地与云端数据独立展示，不相加。
- 费用沿用现有本地价格表的估算，不是服务端实际扣费。本次不迁移历史价格表、不重新计算历史价格或统一第三方供应商币种。
- 移除应用启动时强制从 HRouter 模型广场覆盖本地价格的逻辑；未接入时，定价面板也不会请求或显示 HRouter 模型广场。
