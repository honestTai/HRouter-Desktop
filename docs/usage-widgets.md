# 用量浮窗与 macOS 小组件

## 切换 Agent

- **macOS / Windows 浮窗**：点击左上角 Agent 下拉框，可选择所有支持的 Agent。该选择独立保存，不会更改工作台当前 Agent、供应商、API Key 或路由。
- 从工作台再次点击“桌面用量组件”，会将已打开的浮窗切换到这次选择的 Agent。
- **macOS 14 及以上原生小组件**：在桌面添加 HRouter 后，右键小组件 → 编辑小组件 → Agent。每个小组件可以选择不同 Agent，也可以保留“跟随应用”。
- **macOS 12 / 13**：通知中心的小组件保留“跟随应用”模式；可在工作台或浮窗中切换显示对象。
- Windows 使用浮窗，不安装 macOS WidgetKit 扩展。原生组件的刷新由 macOS 调度，不能保证秒级更新。

## 生成速度与吞吐量不是同一指标

- **生成速度（tok/s）**：来自成功、已完成、非聚合的本地代理请求，使用输出 Token 数除以请求耗时减去首事件等待时间。首事件计时沿用代理的近似口径，不是逐 Token 追踪。
- 优先展示近 5 分钟最多 20 个有效样本的加权速度。窗口内没有样本时，展示**当天最近一次实测值**，明确标注测量时间和非实时含义；隔天不沿用。
- 导入的会话日志通常只有用量，没有生成耗时；不能由 Token 总量、相邻消息时间或 Key TPM 推算生成速度。此时显示“暂无计时”，而不是 `0 tok/s`。
- **Key 吞吐量（tok/min）**：供应商用量接口返回的统计窗口指标，单独展示。值为 0 时显示“当前窗口无吞吐”，不代表上次请求的生成速度为零；该指标可能覆盖共用同一 Key 的多个 Agent。
- 要采集新请求的生成速度，请在支持线路代理的 Agent 中手动启用代理，然后完成一次请求。小组件不会自动改写连接配置，也不会发起模型推理请求。

## 数据与刷新

- 浮窗每 5 秒刷新本地快照；macOS 主窗口在后台每 30 秒刷新所有 Agent 的本地快照。仅已配置当前供应商且启用用量查询的 Agent 才查询财务数据，后台间隔为 60 秒。
- App Group 文件按 Agent 隔离。共享内容仅包含用量、测速、必要的供应商身份/配置指纹与财务摘要，不包含凭据、地址、脚本输出或会话正文。
- 原生小组件只有在 Agent、供应商 ID 和配置指纹全部匹配时才展示财务摘要；超过 5 分钟的财务数据和跨日的今日用量会失效。
- 多个 Agent 的写入合并为一次 WidgetKit 刷新请求，避免逐文件反复消耗系统刷新预算。

## 验证

- React 组件测试覆盖手动选择、独立持久化、切换时清理旧财务数据、无计时/空闲吞吐和后台多 Agent 同步。
- Rust 测试覆盖有效测速、过期窗口回退、未来/失败/聚合/会话样本排除，以及零值和缺失吞吐的区别。
- `bash scripts/test-macos-widget.sh` 使用真实 Swift 源码验证快照隔离、配置、到期与旧格式迁移，并编译真实 app-extension target，检查启动符号和 AppIntents 配置元数据。
